# 📚 Análise e Programação Orientada a Objetos

## Sobre o repositório

Este repositório reúne os exercícios, listas de atividades e exemplos desenvolvidos durante a disciplina de **Análise e Programação Orientada a Objetos**.

O objetivo é registrar a evolução dos conteúdos estudados em sala de aula, colocando em prática os principais conceitos da Programação Orientada a Objetos (POO) por meio de exercícios e desafios propostos ao longo do semestre.

## Conteúdos abordados

* Classes e Objetos
* Atributos e Métodos
* Instanciação de Objetos
* Encapsulamento
* Pacotes (Packages)
* Organização de Projetos
* Boas práticas de programação em Java
* Exercícios e listas de fixação

## Estrutura do repositório

Cada pasta contém exercícios, exemplos ou listas desenvolvidas durante as aulas, servindo como material de apoio para estudos e consultas futuras.

## Tecnologias utilizadas

* Java
* IntelliJ IDEA
